# Bright English School — GitHub Pages Website

Static HTML/CSS/JS website. No build step or external hosting service required.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload the **contents** of this folder to the repository root (`index.html` must be at root).
3. Commit the files.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

## Files
- `index.html` — site and SEO metadata
- `styles.css` — responsive brand styling
- `script.js` — mobile navigation and WhatsApp enquiry form
- `assets/bright-english-school-logo.png` — supplied logo
- `assets/favicon.png` — crest cropped from supplied logo
- `assets/apple-touch-icon.png` — mobile icon
- `assets/admission-poster.jpg` — supplied admission poster

## Enquiry form
The form validates in the browser and opens WhatsApp with a pre-filled enquiry addressed to 9967704588. The visitor must press Send in WhatsApp. The static site does not store submissions.
