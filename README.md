# Bright English School — GitHub Pages Website

A static, responsive school advertising website. No build step, framework, database or hosting service is required.

## Publish on GitHub Pages

1. Create a new GitHub repository (or open the repository you want to use).
2. Extract this ZIP file.
3. Upload **the contents** of the extracted folder to the repository root. `index.html` must be at the root, not inside another nested folder.
4. Commit the files.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then Save.
8. Wait for GitHub Pages to publish the site. Your URL will appear in the Pages settings.

## Included

- `index.html` — complete website structure and SEO metadata
- `styles.css` — responsive styling and brand colours
- `script.js` — mobile navigation and WhatsApp enquiry form
- `assets/bright-english-school-logo.png` — supplied horizontal PNG logo
- `assets/favicon.png` — crest cropped from the supplied logo
- `assets/apple-touch-icon.png` — mobile home-screen icon
- `assets/admission-poster.jpg` — supplied admission poster

## Enquiry form behaviour

The form validates the entered details in the browser and opens WhatsApp with a pre-filled enquiry addressed to **9967704588**. The visitor must press Send in WhatsApp. The static site does not store or transmit form submissions to a database.

## Before publishing

Confirm the admission offer and all contact details with the school. The website presents the “Free Admission” message as the campaign advertised in the supplied poster; no additional eligibility conditions are invented.
